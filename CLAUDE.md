# framework-automation

Gradle multi-project test automation framework, each module a published library: `http-test-automation`, `ui-test-automation` (Playwright), `mobile-test-automation` (Appium).

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `ZurdenRo/test-automation-java`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels, used with their default names. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: `CONTEXT-MAP.md` at the repo root points at one `CONTEXT.md` per module, each with its own `docs/adr/`; root `docs/adr/` holds cross-module decisions. See `docs/agents/domain.md`.
